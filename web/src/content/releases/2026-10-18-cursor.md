RelayAPI 现在可以接入 Cursor 模型账户。管理员配置一次，用户继续使用熟悉的 Relay API 密钥调用模型。

### 从模型账户开始

1. 在管理员工作区打开 **模型账户 → 添加账户 → Cursor**。
2. 填写名称，以及在 Cursor Dashboard 创建的 `crsr_…` API Key。
3. 保存后读取可用模型，在账户配置中选择对外发布范围。

镜像内置并自动管理所需的 SDK 运行时，无需额外部署服务。实际可用模型以账户返回的目录为准。

### 延续现有的接入方式

支持流式输出、函数工具调用和工具结果回传，并沿用 Relay 的计费、订阅限制和执行追踪。用户使用本站 `relay_*` 密钥，无需接触上游 Cursor Key。

> 连续对话请发送完整的会话历史，包括工具调用和工具结果；`previous_response_id` 不能替代完整历史。

### 使用前了解这些边界

- 图片输入使用 base64 data URL，视觉能力取决于实际模型。
- 此适配器不提供图像生成、视频或 Realtime 能力。
- Cursor 网关的用量可能为估算值，本站按网关返回的用量结算。
