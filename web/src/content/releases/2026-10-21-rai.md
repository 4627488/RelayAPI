终端里的常用操作，现在可以一气呵成。rai 新增统一的认证命令，以及密钥、额度、用量和设备管理，让日常操作少几次页面切换。

### 一套命令，管理登录状态

使用 `rai auth` 完成登录、状态检查、切换、刷新和退出。已经保存的服务器可以重复使用，无需每次重新填写地址。

```bash
# 登录并授权账户管理
rai auth login --scope account --server https://your-relay.example.com

# 检查当前授权
rai auth status

# 查看密钥与用量
rai key list
rai usage
```

### 只授予需要的权限

| 授权范围            | 适合什么场景                   |
| ------------------- | ------------------------------ |
| `inference`（默认） | 连接模型，运行 AI 客户端       |
| `account`           | 自助管理密钥、额度与已登录设备 |

**模型调用与账户管理分别授权。** 密钥列表默认不输出密钥明文；创建静态密钥时，需要显式传入 `--show-secret` 才会展示。

### 对人友好，也方便脚本

- `rai key`、`rai device` 默认输出易读的文本。
- 添加 `--json` 可获取结构化结果。
- `rai auth status --json` 可用于自动检查；授权失效时返回非零退出码。
- 旧命令继续兼容，可以按自己的节奏迁移。

> 已经在使用 rai？可以先运行 `rai auth status`，检查当前服务器和授权状态。
