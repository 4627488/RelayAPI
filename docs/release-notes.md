# 站内通知与近期更新

个人与管理员工作区均提供顶部通知信箱，以及侧栏的「近期更新」入口。
通知点击后直达 `/app/updates/<id>` 或 `/admin/updates/<id>`，并将该条标为已读。
仅打开信箱或更新列表不会清除未读状态；可逐条或全部标为已读。

## 发布一条发行说明

1. 在 `web/src/content/releases/` 新增 Markdown 文件，正文从介绍段落开始，子标题使用三级标题。支持 GFM 表格、列表、引用、链接和代码块；不执行原始 HTML。
2. 在 `web/src/lib/releases.ts` 导入正文，在 `releases` 数组开头添加条目，填写唯一的永久 `id`、日期（`YYYY-MM-DD`）、分类、标题和摘要。通知与更新页共用这份目录。
3. 随前端构建部署。不要复用已有 ID，否则会继承旧条目的已读状态。日期按中国时区展示；内容按目录顺序从新到旧排列。

首批内容根据 2026-10-17 至 2026-10-21 的仓库提交与现有文档整理，未虚构版本号。

## 已读状态

已读 ID 使用 `localStorage` 的 `relayapi.inbox.v1.<tenant-id>` 保存，按账户隔离，个人与管理员工作区共用。
同一页面内和同源浏览器标签页之间同步；浏览器存储不可用时退回内存状态。
当前实现不需要新建后台服务或数据表，不提供跨设备同步、运营后台编辑和定向消息投递。
